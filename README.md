# Zenvora  B2B SaaS Website

Zenvora is a modern B2B SaaS website created to demonstrate a professional software-company website with a clean interface, clear messaging, and conversion-focused sections.

The project focuses on presenting a SaaS product in a simple and professional way for business users.

## Live Demo

[View Zenvora Live](https://munazza-shan-web.github.io/zenvora-b2b-saas/)

## Features

* Modern SaaS landing page
* Responsive design
* Hero section with clear CTA
* Product features
* Business solutions
* Pricing section
* Customer testimonials
* FAQ section
* Contact section
* Responsive navigation
* Conversion-focused layout

## Technologies

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
